# LLM-maker marks

Thirty-two marks for the Home orbit and the About mark swarm, all rendered as #f2f2f2 silhouettes
on transparency (256 px PNG) so they sit in the monochrome world. Trademarks belong to their
owners; they are shown for reference, not endorsement, and the site says so under the orbit.

- **Six earlier marks** (claude, openai, deepseek, qwen, antigravity, withone): rasterised from
  `../nano-logos/*.svg` (Lobe Icons, MIT, and a traced One mark; see that folder's README).
- **Twenty-six from Logo.dev** (2026-10-13): resolved with the One CLI's logo-dev Search Brands
  action on the `jws-logo` connection, downloaded in greyscale from the logo URLs it returned, then
  converted to silhouettes (`Tasks/2026-10-13-cosmic-journey/process-logos.cjs`): app-tile
  backgrounds removed, marks trimmed and fitted. Google Gemini has no separate Logo.dev brand, so
  Google DeepMind stands in for it. Nous Research (an illustration) and ElevenLabs (not an LLM
  maker) were left out.

Order and orbit ring: inner ring = the six earlier marks; middle ring = Anthropic, Google DeepMind,
Meta, Mistral AI, xAI, Moonshot AI, Zhipu AI, MiniMax, Perplexity, NVIDIA, Microsoft, OpenRouter;
outer ring = Cohere, Hugging Face, Groq, AI21 Labs, StepFun, ByteDance, Tencent, Baidu, Amazon,
IBM, Liquid AI, Reka, Ai2, Inflection AI.
