DeepSeek V4.1-Flash-1017: what changed, and what it costs

October 27, 20267 min read1456 words

DeepSeek released V4.1-Flash-1017 on October 17, 2026. It is an update to DeepSeek-V4.1-Flash, with open weights under the MIT license and a 1M-token context. DeepSeek's own table shows gains on several tests, and Claude Opus 5 still leads on others. Artificial Analysis lists it at $0.30 per million input tokens and $1.20 per million output tokens.

Key takeaways

  • The release is dated October 17, 2026. The weights are on Hugging Face under MIT, with a 1M-token context.
  • The largest absolute gain in DeepSeek's table is Terminal-Bench 4.0, up from 31.2 to 42.3. Every benchmark number here is vendor-reported.
  • On its Intelligence Index run, Artificial Analysis counted 210M output tokens, against a median of 140M. A low price per token can still give a high bill.
  • Test it on your own tasks before you switch. The method is below.

What is DeepSeek V4.1-Flash-1017?

DeepSeek's news page dates the release to October 17, 2026. It calls the model "a Pareto improvement in performance and cost," with "stronger benchmark performance, faster task completion, and shorter outputs than the previous version" (DeepSeek news). The model card says it "reduces task execution time and output length" (model card). Both are DeepSeek's claims. Three facts you can check today:

  • Where it runs: DeepSeek says the model is "now live on our website, app, and API."
  • Weights: the model card says the MIT license covers "this repository and the model weights." The weights are on Hugging Face.
  • Context: the model card lists a 1M-token context window.

The news page doesn't state a model price. The price figures later in this post come from Artificial Analysis.

Two footnotes on the card matter when you read the table. The HLE row is marked with a dagger for the text-only subset. DeepSeek says it used the Claude Code harness for Terminal-Bench 4.0 and the Mini-SWE-V2 harness for DeepSWE v1.1. Harness choice can change scores, so these numbers aren't directly comparable with other people's runs. Where the new model leads: DeepSWE v1.1 (77.0 against Opus 5's 74.0), Automation-Bench (60.5 against 50.3) and Apex Bench (72.1 against 65.8). Where Opus 5 still leads: HLE, Terminal-Bench 4.0, ProgramBench and NL2Repo-Bench. The gap on Terminal-Bench 4.0 is 9.5 points, and on HLE it is 13.7 points.

What changed from V4.1-Flash, row by row

The title asks what changed, so here is the gap on each row, worked out from the card's own numbers:

  • Terminal-Bench 4.0: up 11.1 points (31.2 to 42.3)
  • ProgramBench: up 8.8 (20.3 to 29.1)
  • Apex Bench v1.1: up 7.5 (64.6 to 72.1)
  • HLE (w/o tools): up 5.8 (36.8 to 42.6)
  • Automation-Bench v1.0.6: up 5.7 (54.8 to 60.5)
  • DeepSWE v1.1: up 2.8 (74.2 to 77.0)
  • NL2Repo-Bench: up 2.8 (65.4 to 68.2)

Every row went up. The biggest gains are on the terminal and programming tests, and the smallest are on DeepSWE and NL2Repo-Bench, at 2.8 points each. This is the vendor's own before-and-after, run on the vendor's chosen harnesses, so treat it as a claim to check, not a measurement. The card names each benchmark but doesn't explain what each one measures, so I don't describe the tests beyond their names here. Read each benchmark's own page before you repeat one of these numbers to a client.

What does an independent check say?

Artificial Analysis is a third party, and its page reports its own runs. Its page lists the model as "DeepSeek V4.1 Flash 1017 (Max)." It scores 45 on the Intelligence Index and outputs 203.7 tokens per second. The page compares that speed with a median of 73.2 tokens per second for open-weight models of similar size. The Intelligence Index run cost $0.26 per task on average. The same page reports the token count. The Intelligence Index run generated 210M output tokens. Artificial Analysis calls that "very verbose in comparison to the median of 140M." That looks like a contradiction with DeepSeek's claim of shorter outputs. The two sources measure different things. DeepSeek's claim is about its own tests. The Artificial Analysis figure is one index run of the "(Max)" configuration. The page doesn't compare the new model with the previous version, so this post makes no before-and-after claim. What this means for you: if you pay per output token, check the output length on your own tasks. A cheap price per token can still be an expensive run.

What does it really cost?

Artificial Analysis lists the price at $0.30 per million input tokens and $1.20 per million output tokens. The sums below use those prices. They are illustrative arithmetic, not a measured run. Take 1,000 agent tasks, each with 20,000 input tokens and 2,000 output tokens:

  • Input: 20M tokens at $0.30 per million is $6.00.
  • Output: 2M tokens at $1.20 per million is $2.40.
  • Total: $8.40.

Now suppose the same tasks write 3,000 output tokens each, which is 50% more. The output side becomes $3.60, and the total is $9.60. The input cost doesn't change. That is the verbosity effect in one line: the output side grows with the length of the answer. DeepSeek's news page doesn't give model prices, so this post doesn't add any.

What else shipped with it?

DeepSeek also opened its Search and Fetch APIs. The news page lists "$0.75 per 1,000 calls" for each endpoint. Calls made through server-side tools in DeepSeek Harness, Claude Code and Codex are "currently free for DeepSeek API users." Billing starts on October 31, 2026, at 16:00 UTC. If you run research steps through those tools, the free window is short. Check the DeepSeek news page before you plan a budget around it.

Who should switch, and who should wait?

Automation-heavy agent runs. Automation-Bench is the row where the new model beats both V4.1-Flash and Opus 5 in DeepSeek's table (60.5, 54.8 and 50.3). If most of your agent steps are structured automations, this is the case to test first. Watch the output length. Coding agents. The table splits. The new model leads on DeepSWE v1.1, but Opus 5 leads on Terminal-Bench 4.0 by 9.5 points. Run your own coding tasks before you move a coding agent. Hard reasoning. On HLE, Opus 5 scores 56.3 against 42.6 for the new model, per DeepSeek's card. Keep the stronger model for this kind of work until your tests say otherwise.

How I'd test it before switching

This is my method, not a result. I haven't tested this model, and I make no claim about how it performs on your work.

  1. Pick 10 to 20 real tasks from your own agent runs. Choose tasks where you can tell a pass from a fail.
  2. Run each task on your current model and on V4.1-Flash-1017, with the same prompt and the same tools.
  3. Log four numbers per task: pass or fail, input tokens, output tokens and cost.
  4. Read the outputs for length. If the new model writes much more, the price gap may close.
  5. Switch only the steps where the new model passes as often as the old one.

Keep the test small enough to finish in an afternoon. A switch that passes 10 of 10 tasks and costs less per run is worth more than a benchmark you can't reproduce.

Frequently asked questions

Is DeepSeek V4.1-Flash-1017 open source?

The model card says the MIT license covers "this repository and the model weights." The weights are on Hugging Face (model card).

How much does it cost?

Artificial Analysis lists $0.30 per million input tokens and $1.20 per million output tokens (Artificial Analysis). DeepSeek's news page doesn't list model prices. Check DeepSeek's pricing page before you budget.

Is it free?

The sources don't say whether the web app is free. The API is priced per token, as above. Search and Fetch calls made through server-side tools are free for now. Billing starts on October 31, 2026, at 16:00 UTC (DeepSeek news).

What is it used for?

The model card reports results on coding, terminal and automation tests. It doesn't list intended uses, so the uses here are the tests DeepSeek chose to report.

Is it better than Opus 5?

It depends on the test. In DeepSeek's table, Opus 5 leads on HLE, Terminal-Bench 4.0, ProgramBench and NL2Repo-Bench. V4.1-Flash-1017 leads on DeepSWE v1.1, Automation-Bench and Apex Bench. These are vendor-reported numbers, so run your own test before you choose.
