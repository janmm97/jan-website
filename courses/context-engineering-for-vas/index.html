What's inside

When you finish, you can read a context map, choose between /clear, /compact and /rewind, load context only when needed, keep the prompt cache warm, clean inputs before they reach your agent, track cost, and write a context plan. AI apps change often. App steps are dated (as of 2026-11).

  1. 6.1 What fills your agent's memory. Run /context, name the layers that fill it, and remove the biggest one you don't need. (15 min)
  2. 6.2 More is not better, context rot. Explain why a full context makes answers worse, and cut a memory file to its essentials. (15 min)
  3. 6.3 Clear, compact or rewind. Choose /clear, /compact, /rewind or a new session for a situation, and add compact instructions to your memory file. (20 min)
  4. 6.4 Just-in-time context. Give your agent paths instead of contents, use subagents for noisy work, and keep a NOTES.md between sessions. (20 min)
  5. 6.5 Prompt caching, keep the start the same. Explain how prompt caching works, name 5 things that break the cache, and read the cache line in /usage. (20 min)
  6. 6.6 Clean inputs before they go in. Remove private data you don't need, wrap untrusted text in clear tags, and check 5 inputs before an agent reads them. (20 min)
  7. 6.7 Tokens, models and cost. Pick a model and effort level for a task, read /usage, and keep a one-week cost log. (15 min)
  8. 6.8 Your one-page context plan. Write a one-page context plan for an agent, sorting its information into always, on demand and never. (15 min)
