What's inside

When you finish, you can explain APIs and webhooks to a client, read JSON, make a simple API call, read an API doc, and know what to do when a call fails. AI apps change often. App steps are dated (as of 2026-11).

  1. 2.1 The restaurant: what an API is. Explain an API as a waiter between you and the kitchen, in 3 sentences. (12 min)
  2. 2.2 Your first API call. Open a public API address in your browser and read one value from the answer. (10 min)
  3. 2.3 Reading JSON without fear. Find any value in a JSON answer by following its keys and lists. (15 min)
  4. 2.4 Requests: GET, POST and friends. Match a VA job to the right request type: read, create, update or delete. (12 min)
  5. 2.5 Keys, logins and keeping them secret. Explain API keys versus OAuth sign-in, and store a key safely. (15 min)
  6. 2.6 Webhooks: the doorbell. Explain a webhook as a doorbell, compared with checking the door again and again (polling). (12 min)
  7. 2.7 Read an API doc. Find the endpoint, method, required fields and limits in a real API doc. (15 min)
  8. 2.8 When it fails: errors and limits. Read the errors 401, 403, 404, 429 and 500, and know the next step for each. (15 min)
