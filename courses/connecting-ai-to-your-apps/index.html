What's inside

When you finish, you can explain MCP and integration layers, connect apps with the right access level, run app actions from a chat app and from your agent, check what ran, and spot prompt injection. AI apps change often. App steps are dated (as of 2026-11).

  1. 5.1 Why agents need "hands". Explain why a model alone can't send an email, and what gives it the power to. (10 min)
  2. 5.2 MCP, the universal plug. Explain MCP in plain words, as a standard plug between AI apps and tools. (12 min)
  3. 5.3 Integration layers. Explain what an integration layer like One handles, and compare it with connecting each app yourself. (12 min)
  4. 5.4 Set up One, read-only first. Create a One account and connect two apps with the right access level, starting read-only. (15 min)
  5. 5.5 One MCP in Claude or ChatGPT. Add One MCP to a chat app and run one read action to get a calendar brief. (20 min)
  6. 5.6 One CLI inside your agent. Install the One CLI and have your agent find, read and run an app action. (25 min)
  7. 5.7 Safe actions, approvals and logs. Match access to the job, require approval for sending, and check what actually ran. (15 min)
  8. 5.8 Prompt injection, when emails try to boss your agent. Spot an injected instruction in content your agent reads, and set rules and limits against it. (15 min)
  9. 5.9 Alternatives, a fair comparison. Name two alternatives to One and say when each fits. (10 min)
